# 🎵 Эквалайзер

Локальный аудиоплеер с живым визуализатором, 10-полосным эквалайзером, звуковыми эффектами и текстами песен. Всё работает прямо в браузере — файлы не отправляются на сервер, а настройки сохраняются на устройстве.

## ✨ Возможности

**🎧 Плеер**
- Воспроизведение локальных файлов: MP3, WAV, OGG, M4A, FLAC, WebM, а также видео MP4/WebM (играет звуковая дорожка)
- Чтение метаданных (название, исполнитель, альбом, обложка) через `jsmediatags`
- Перетаскивание файлов (drag & drop), плейлист с изменением порядка, поиск по плейлисту
- Избранное и история прослушивания (до 100 записей)
- Перемешивание, повтор (выкл / все / один), петля A–B, таймер сна (15–90 мин), кроссфейд, скорость 0.5–2×

**🎚️ Эквалайзер и звук**
- 10-полосный эквалайзер: 31 Гц – 16 кГц, диапазон ±12 дБ
- Пресеты: Плоский, Бас, Вокал, Высокие, Вечеринка
- Усиление баса, эхо (delay + feedback), реверберация (convolver), 8D-звук (кружение в наушниках)

**🌈 Визуализатор**
- 5 режимов: Столбцы, Зеркало, Круг, Волна, Частицы (Canvas, без ре-рендеров React — через `requestAnimationFrame`)
- Настройка: число столбцов, зазоры, скругление, сглаживание, чувствительность, отражение
- 4 режима цвета: Градиент, Сплошной, RGB-поток, По частотам + неоновое свечение
- Автопалитра: цвета визуализатора берутся из обложки трека
- Реакция на бит и режим «Вечеринка» — картинка пульсирует в такт музыке

**📝 Текст песни**
- Синхронизированные тексты LRC с пословной подсветкой (караоке)
- Загрузка `.lrc` / `.txt`, ручная синхронизация (штамп времени, сдвиг), экспорт в LRC
- Онлайн-поиск текста через [lrclib.net](https://lrclib.net) и перевод строк (RU/EN) через MyMemory

**🎨 Интерфейс**
- Тёмная и светлая темы, центральный текст с «волной» букв от баса, надпись в углу
- Свои пресеты оформления: экспорт/импорт JSON и шаринг ссылкой
- Запись визуализатора в WebM, мини-плеер Picture-in-Picture, запись с микрофона
- Все настройки сохраняются в `localStorage`

## 🛠️ Технологии

React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · Web Audio API · Canvas · `jsmediatags` · `lucide-react`

Сборка — в один HTML-файл (`vite-plugin-singlefile`): весь CSS и JS инлайнятся, отдельный сервер не нужен.

```
├── index.html                  # точка входа (подключает /src/main.tsx)
├── vite.config.ts              # Vite + Tailwind + singlefile, алиас @ → src
├── tsconfig.json
└── src/
    ├── main.tsx                # монтирование React
    ├── App.tsx                 # корневой компонент: связывает хуки и панели
    ├── types.ts                # все типы: Settings, Track, LyricLine, ...
    ├── index.css               # стили и тема (CSS-переменные)
    ├── jsmediatags.d.ts        # декларация типов для jsmediatags
    ├── components/             # UI-компоненты
    │   ├── VisualizerCanvas.tsx  # канвас-визуализатор (5 режимов)
    │   ├── PlayerControls.tsx    # кнопки плеера, прогресс, громкость
    │   ├── Playlist.tsx          # плейлист, избранное, история, поиск
    │   ├── SettingsPanel.tsx     # панель настроек (секции)
    │   ├── EqualizerPanel.tsx    # 10-полосный эквалайзер + пресеты
    │   ├── EffectsPanel.tsx      # эхо, реверб, 8D, скорость
    │   ├── LyricsPanel.tsx       # текст песни, перевод, синхронизация
    │   ├── CenterText.tsx        # центральный текст с волной букв
    │   ├── Branding.tsx          # надпись в углу экрана
    │   ├── ColorControl.tsx      # выбор цвета (HEX + RGB)
    │   ├── Controls.tsx          # базовые контролы: слайдеры, переключатели
    │   ├── EmptyState.tsx        # экран без треков
    │   └── SettingsButton.tsx    # кнопка открытия настроек
    ├── hooks/                  # React-хуки (логика)
    │   ├── useAudioEngine.ts     # Web Audio граф: EQ, эхо, реверб, 8D, запись
    │   ├── useSettings.ts        # настройки + пресеты + localStorage
    │   ├── useLibrary.ts         # избранное и история
    │   ├── useLyrics.ts          # загрузка/синхронизация/перевод текстов
    │   ├── useBeatDetection.ts   # уровни баса/средних/высоких и детект бита
    │   └── usePictureInPicture.ts# мини-плеер поверх других окон
    └── utils/                  # чистые утилиты
        ├── audio.ts              # EQ-пресеты, метаданные, миниатюры, хэши
        ├── color.ts              # HEX/RGB/HSL, градиенты, палитры
        ├── format.ts             # время, дБ, проценты, clamp/lerp
        ├── lrcParser.ts          # парсер и сериализатор LRC
        ├── lyricsApi.ts          # lrclib.net + MyMemory
        ├── palette.ts            # доминантные цвета обложки
        ├── storage.ts            # localStorage, шаринг, буфер обмена
        └── cn.ts                 # clsx + tailwind-merge
```

## 🚀 Установка и запуск

### Вариант 1 — без установки (готовый файл)

1. Скачайте ZIP из раздела [Releases](../../releases) — файл `equalizer-v1.0.0.zip`.
2. Распакуйте архив в любую папку.
3. Откройте `index.html` двойным кликом в браузере (Chrome, Edge, Firefox, Safari).
4. Перетащите на страницу свои аудиофайлы — и слушайте 🎧

> Никаких зависимостей и сервера не нужно: приложение — один HTML-файл.

### Вариант 2 — из исходного кода

Требуется [Node.js](https://nodejs.org) 18+.

```bash
git clone https://github.com/eblanchik14886767-cmyk/arenatest.git
cd arenatest
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # продакшн-сборка → dist/index.html (один файл)
npm run preview  # предпросмотр собранной версии
```
